POST /physical/order-status

Operation ID: postPhysicalOrderStatus.

Authentication: API key in the header (APIKey) or API key in the header (HMACSignature) or API key in the header (Timestamp).

Request body

application/json

Property Type Required Description
references array of string (uuid) Yes Array of order references to check. Each reference should be a UUID from a previous order-card request. Returns status information for each reference, including 'not found' for references that don't exist.
