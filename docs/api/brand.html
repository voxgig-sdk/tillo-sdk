GET /brands

Operation ID: getBrands.

Authentication: API key in the header (APIKey) or API key in the header (HMACSignature) or API key in the header (Timestamp).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | brand | query | string | No | Filter by a specific brand slug | | detail | query | boolean | No | Include detailed brand information | | country | query | string | No | Filter brands based on the country, provide the two-character ISO 3166-1 alpha-2 country code (eg. GB, FR, US). Must be uppercase | | currency | query | enum: AED, AUD, BHD, BRL, CAD, CHF, ... | No | Filter brands based on the currency, please provide the three-character ISO 4217 currency code (eg. GBP, EUR, USD). Must be uppercase | | category | query | enum: baby, beauty, books, cars, charity, craft, ... | No | Filter brands based on the category slug (eg. fashion, gaming) |

Responses

200: List of brands with optional filtering and detail
