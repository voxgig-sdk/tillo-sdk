POST /physical/activate

Operation ID: postPhysicalActivate.

Authentication: API key in the header (APIKey) or API key in the header (HMACSignature) or API key in the header (Timestamp).

Request body

application/json

Property Type Required Description
brand string Yes Brand identifier/slug (lowercase letters, numbers, hyphens only). Must be a brand connected to your buyer account.
client_request_id string Yes Unique identifier for this request. Also acts as an idempotency key
code string Yes
face_value object Yes
face_value.amount string or number (float) Yes Amount in the brand's currency. Accepts string or number with up to 2 decimal places. Minimum and maximum amounts depend on the buyer↔brand configuration. Use the brand discovery endpoint to retrieve valid denomination ranges. Returns 400 if the amount is outside the allowed range for the buyer↔brand combination.
face_value.currency enum: AED, AUD, BHD, BRL, CAD, CHF, ... Yes
pin string No
sector enum: affiliate-marketing, aggregator, b2c-marketplace, cashback, cash-out, charity, ... Yes Must match one of the sectors configured for your buyer account.
tags array of string or number No Optional meta data associated with the issuance.
