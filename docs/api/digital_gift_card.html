create

POST /digital/check-balance

Operation ID: postDigitalCheckBalance.

Authentication: API key in the header (APIKey) or API key in the header (HMACSignature) or API key in the header (Timestamp).

Request body

application/json

Property Type Required Description
brand string Yes Brand identifier/slug (lowercase letters, numbers, hyphens only). Must be a brand connected to your buyer account.
client_request_id string Yes Unique identifier for this request. Also acts as an idempotency key
code string No Gift card code
face_value object Yes
face_value.currency enum: AED, AUD, BHD, BRL, CAD, CHF, ... Yes
original_client_request_id string No This field will be the client_request_id provided in the original transaction. For example, if you are performing some form of cancellation, then this would be the client_request_id you provided when making the original issuance request
pin string No Gift card PIN. This field is optional and only some brands will require this to be added.
reference string (uuid) No This is the reference you received when making the original issuance request.
sector enum: affiliate-marketing, aggregator, b2c-marketplace, cashback, cash-out, charity, ... Yes Must match one of the sectors configured for your buyer account.
serial_number string No The serial number is a required parameter for any Sainsburys brand
