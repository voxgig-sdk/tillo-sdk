POST /float/request-payment-transfer

Operation ID: postFloatRequestPaymentTransfer.

Authentication: API key in the header (APIKey) or API key in the header (HMACSignature) or API key in the header (Timestamp).

Request body

application/json

Property Type Required Description
amount string or number (float) No Amount to transfer. Accepts either a string or number. String amounts can have any number of decimal places (for example, "300.1000000000001") and will be normalized to 2 decimal places in the response. Minimum value is 0.01, maximum is 99,999,999.99.
currency enum: AED, AUD, BHD, BRL, CAD, CHF, ... No
finance_email string (email) No Optional finance email address to override the default recipient. Required if partner has no default finance email configured.
float string Yes Float identifier from the check-floats endpoint (for example universal-float, brand-specific float name)
payment_reference string No Optional payment reference. If not provided, Tillo will generate one automatically. Uniqueness is not enforced, but unique references are recommended.
proforma_invoice object No Optional proforma invoice company details override. Only available if partner has proforma invoicing feature enabled. If provided, company_name is required.
proforma_invoice.address_line_1 string No
proforma_invoice.address_line_2 string No
proforma_invoice.address_line_3 string No
proforma_invoice.address_line_4 string No
proforma_invoice.city string No
proforma_invoice.company_name string Yes
proforma_invoice.contact_name string No
proforma_invoice.country string No
proforma_invoice.county string No
proforma_invoice.post_code string No
proforma_invoice.vat_number string No

GET /float/transfer-requests

Operation ID: getFloatTransferRequests.

Authentication: API key in the header (APIKey) or API key in the header (HMACSignature) or API key in the header (Timestamp).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | float | query | string | No | Specifies the target float (for example, "universal-float", "amazon", "reward-pass") | | currency | query | enum: AED, AUD, BHD, BRL, CAD, CHF, ... | No | Optional filter to return transfer requests for a specific currency only. Provide the three-character ISO 4217 currency code (eg. GBP, EUR, USD). Must be uppercase. | | payment_reference | query | string | No | The payment reference to filter transfer requests | | start_date | query | string (date) | No | Beginning of the date range in ISO 8601 format | | end_date | query | string (date) | No | End of the date range in ISO 8601 format | | status | query | enum: pending, approved, approved_edited, removed, cancelled | No | Filter for transfer request state |
